# Feeligrane

> **Reveal the emotional watermark of long-form writing.**

Feeligrane is an open-source browser extension that helps readers explore affective patterns in long-form writing.

Rather than attempting to infer an author's psychology, Feeligrane highlights linguistic cues that may relate to themes such as guilt, shame, self-criticism, repair, gratitude, validation, vulnerability and other affective dimensions.

The objective is not to replace human interpretation, but to make recurring textual patterns easier to notice, annotate and study.

---

# Vision

Reading is an interpretative act.

Feeligrane aims to support that act by making explicit certain lexical and rhetorical patterns that often remain unnoticed.

The extension is intended for readers, writers and researchers interested in the structure of discourse rather than in psychological diagnosis.

---

# Principles

- Human interpretation comes first.
- Transparency over opacity.
- Local-first whenever possible.
- AI is optional, never mandatory.
- Every annotation should remain explainable.
- Methodology should remain reproducible.

---

# Features (planned)

- Lexical detection of affective markers.
- Configurable annotation categories.
- Sidebar for exploration and navigation.
- Manual annotations.
- Export to Markdown and JSON.
- Optional AI-assisted analysis.
- Local-first workflow whenever possible.

---

# Project status

Feeligrane is currently in its early design phase.

The repository is establishing:

- its methodological foundations;
- its governance model;
- its annotation taxonomy;
- the first browser extension prototype.

Implementation will begin once these foundations are stable.
