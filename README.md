# Feeligrane
A browser extension for annotating affective patterns in long-form writing.

> Reveal the emotional watermark of long-form writing.

Feeligrane is an open-source browser extension designed to help readers explore affective patterns in long-form texts.

Rather than attempting to infer an author's psychology, Feeligrane highlights linguistic cues that may correspond to themes such as guilt, shame, self-criticism, repair, validation, gratitude or vulnerability.

The project aims to assist readers, writers and researchers by making these recurring textual patterns easier to notice, annotate and study.

## Principles

- Human interpretation comes first.
- Local-first whenever possible.
- AI is optional, never mandatory.
- Transparent annotation.
- Reproducible methodology.
